## 能力描述

选题库的读写字段映射与操作 SOP（connector_io 类，本资产不真实读写外部系统）。SOP 六步：确认表结构 → 字段映射（R/W 方向 + 具体示例值）→ 读取步骤（时间窗/筛选/限速 ≤ 5 次/秒、单页 ≤ 100 条）→ 写入步骤（去重键、失败重试 ≤ 3 次）→ 权限与只读边界（最小授权，仅目标表）→ 回执核对（计划 N 条 / 实际 M 条，差异逐条列出）。

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `system` | string | ✅ | 需要读写的系统名称（如企业微信、抖店后台） |
| `task` | string | ✅ | 要读什么、要写什么 |

## 输出规格

连接器数据读写

- `field_map`：系统字段与资产字段的对应关系
- `operation`：用户需要在其平台上执行的步骤
- `limitation`：明确声明本资产不能自动完成该操作

## 使用步骤

### 方式一：直接使用（最快）

1. 打开任意支持自定义提示词的 AI 工具
2. 复制 `prompt.txt` 的**全部内容**作为系统提示词
3. 按上方「输入规格」提供数据
4. 得到符合「输出规格」的结果

### 方式二：在主流平台导入

| 平台 | 导入方式 |
|------|---------|
| **Coze / 扣子** | 新建 Bot → 人设与回复逻辑 → 粘贴 `prompt.txt` |
| **WorkBuddy** | 新建 Skill → 填入 `prompt.txt` 内容 |
| **Dify** | 新建应用 → 提示词编排 → 粘贴 `prompt.txt` |
| **Claude** | 新建 Project → Instructions → 粘贴 `prompt.txt` |
| **ChatGPT** | 新建 GPT → Instructions → 粘贴 `prompt.txt` |

## 边界（不做的事）

- ❌ 编造数据、案例或效果承诺
- ❌ 使用违反《广告法》的极限词
- ❌ 生成诱导好评、刷量、删差评等违规内容
- ❌ 执行或建议任何绕过平台规则的操作
- ❌ 涉及资金操作或代替用户做最终决策
- ❌ 处理超出本职能力范围的请求（应明确说明并建议转其他技能）

## 操作清单

1. 用户在飞书打开「内容选题库」多维表格，确认「选题池」数据表包含上述字段，缺字段先在表格视图手动补建
2. 在抖音创作者后台导出 9.29-10.5 的逐条视频 CSV（列：标题/发布日期/播放量/完播率/净增粉丝）
3. 用飞书表格的「导入」或「智能表格-粘贴」把 CSV 逐行粘贴到选题池对应列，粘贴前核对标题与已有选题行匹配
4. 对完播率列做一次性格式处理：统一为百分数（如 34.2%），避免小数与百分数混存
5. 新增 3 行写入下周选题：填标题、形式（从单选下拉选「情境对话卡点」）、计划发布日期（周二/四/六 18:30）、负责人（从人员选择器选主理人）
6. 把 3 行的「状态」字段设为「待拍」，并分享表格给外包剪辑师（可编辑权限）以便排期
7. 写入完成后在表格视图按「计划发布」升序检查 3 条新选题是否落在正确日期
