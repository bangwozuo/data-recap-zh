### 示例 2：归因分析

**能力**：内容特征与数据表现的关联归因

**输入**：

```json
{
  "data": {
    "曝光": 12000,
    "点击": 480,
    "转化": 32
  }
}
```

**输出**：

## 核心结论

本周曝光增长 62% 来自 Reddit 单帖爆发，其余渠道基本持平。

## 驱动因素

1. **Reddit 热帖** — 贡献 62% 增量，帖子进入 subreddit 首页
2. **X 转发** — 贡献 18%，主要来自 2 个 KOL 转发
3. **自然搜索** — 贡献 12%，长尾词开始见效

## 置信度

**中** — 数据来源为用户手动导出，样本周期仅 1 周

## 下一步行动

1. 拆解那条 Reddit 热帖的结构（标题 / 首段 / 配图 / 发布时间）
2. 下周复用该结构发 3 篇，验证可复制性
3. X 侧主动联系 5 个同领域 KOL，建立长期关系

**资产位置**：`skills/attribution-analysis/`

### 示例 4：报告排版

**能力**：数据报告结构化排版输出

**输入**：

```json
{
  "metrics": {
    "流水": 4860,
    "客流": 128,
    "差评数": 0
  }
}
```

**输出**：

## 一句话结论

今天生意比昨天好，但晚市时段客流下滑 18%。

## 关键指标

| 指标 | 今日 | 昨日 | 变化 |
|------|------|------|------|
| 流水 | ¥4,860 | ¥4,320 | ↑ 12.5% |
| 客流 | 128 | 119 | ↑ 7.6% |
| 差评数 | 0 | 0 | — |

## 异常预警

**有** — 晚市 19:00-21:00 客流仅 32 人，显著低于该时段均值（52 人）

## 行动建议

1. 检查今晚周边是否有活动分流（商场促销 / 社区活动）
2. 若连续 3 天晚市低于均值，考虑调整晚市套餐结构
3. 明天关注同一时段，确认是偶发还是趋势

**资产位置**：`skills/report-layout/`
